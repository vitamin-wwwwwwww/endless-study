# Endless Study 設計書

- 作成日: 2026-11-12
- 対象: iPhone 用 勉強記録アプリ 初版 (v1)

## 1. 目的

ジャンルを固定せず、気の向くままに勉強した内容を記録できるアプリを作る。
記録するたびに「続けている」という実感と、ちょっとした射幸心が得られることを最重要の体験とする。

### 成功基準

- 記録開始まで 2 タップ以内（タイマー開始 / 手入力画面を開く）
- タグもメモも付けずに記録を保存できる
- 記録を保存した直後に、必ず何かしらの報酬フィードバック（XP 獲得、レベルアップ、バッジ、ガチャ券）が返る
- 連続日数と積み上げ量がホーム画面と草カレンダーで一目でわかる

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 記録の形 | 自由記録 + 任意タグ（資格・言語などの目標設定はしない） |
| 実装方式 | ネイティブ (SwiftUI + SwiftData)、iOS 17 以上、外部ライブラリなし |
| 記録方法 | タイマー計測と手入力の両方 |
| ごほうび要素 | 連続日数 + 草カレンダー / XP・レベル / ガチャ / 実績バッジ（すべて初版に入れる） |
| プロジェクト生成 | XcodeGen (`project.yml`) |

### 検討した代替案

- **Core Data (iOS 16 対応)**: 対応端末は広がるがコード量が増える。個人利用が前提のため不採用。
- **JSON ファイル保存**: 最も単純だが、集計や将来の iCloud 同期で不利。不採用。

## 3. 画面構成

タブ 3 つの構成とする。

### 3.1 ホーム

- 連続日数（ストリーク）
- 現在レベルと次レベルまでの XP バー
- 今日の勉強時間
- 「タイマー開始」ボタン（計測中は経過時間と「停止」ボタンに切り替わる）
- 「手入力」ボタン

### 3.2 記録

- 草カレンダー: 直近約 26 週間を週単位の格子で表示。日別の合計分数で 5 段階の濃淡（0 分 / 1〜29 分 / 30〜59 分 / 60〜119 分 / 120 分以上）
- タグ別累計時間（タグなしは「タグなし」としてまとめる）
- 履歴一覧（新しい順）。各記録は編集・削除できる

### 3.3 コレクション

- ガチャ: 所持券数の表示と「引く」ボタン、抽選演出
- 獲得した景品（称号・テーマ色）の一覧。未獲得はシルエット表示。装備する称号とテーマ色を選べる
- 実績バッジ一覧。未解除は条件を表示

## 4. 記録フロー

### 4.1 タイマー

1. 「タイマー開始」で開始日時を保存する（経過秒をカウントするのではなく、開始日時との差分で経過時間を算出する）。これによりアプリを閉じても、端末を再起動しても計測が継続する。
2. 「停止」で保存シートを表示する。計測時間は分単位に切り上げる（1 分未満も 1 分とする）。
3. タグ（任意）とメモ（任意）を入力して保存する。「破棄」も選べる。
4. 計測時間の上限は 12 時間とし、超えた場合は 12 時間として扱う（止め忘れ対策）。保存シートで分数を修正できる。

### 4.2 手入力

- 日付（既定は今日、未来日は不可）、分数（1〜720）、タグ（任意）、メモ（任意）を入力して保存する。

### 4.3 保存直後の報酬表示

保存すると結果画面を表示する。

1. 獲得 XP の表示と触覚フィードバック
2. レベルアップした場合はその演出
3. 新たに解除したバッジがあれば表示
4. ガチャ券が付与された場合はその旨を表示し、コレクション画面へ誘導

### 4.4 タグ

- 保存シート上でその場で新規作成できる（名前と色）。
- 既存タグは最近使った順に並べ、1 タップで選べる。
- タグを削除した場合、そのタグが付いていた記録は「タグなし」になる（記録自体は消えない）。

## 5. ごほうびルール

### 5.1 XP とレベル

- 1 分 = 1 XP。ガチャのダブりによるボーナス XP を加算する。
- レベル L に到達するための累計 XP は `50 × L × (L − 1)`（Lv1 = 0、Lv2 = 100、Lv3 = 300、Lv4 = 600 …）。
- レベル上限は設けない。

### 5.2 連続日数

- その日に合計 1 分以上の記録があれば「勉強した日」とする。
- 日付の区切りは端末のローカル時刻の 0 時。
- 現在の連続日数は、今日（今日まだ記録がなければ昨日）から遡って連続する「勉強した日」の数。昨日も今日も記録がなければ 0。
- 最長連続日数も表示する。

### 5.3 ガチャ

- 15 分以上の記録 1 件につき券 1 枚を付与する。付与は記録の日付ごとに 1 日 3 枚まで（短い記録を連打する水増しの防止）。
- 記録を後から編集・削除しても、付与済みの券と獲得済みの景品は取り消さない。編集による追加付与も行わない（付与判定は新規保存時のみ）。
- 排出率: N 70% / R 25% / SR 4.5% / SSR 0.5%。レアリティを決めた後、そのレアリティの景品から等確率で 1 つ選ぶ。
- 景品は称号とテーマ色の 2 種類。初版の景品数は N 12 / R 8 / SR 4 / SSR 2 の計 26 個を目安とする。
- すでに持っている景品が出た場合はボーナス XP に変換する（N 10 / R 30 / SR 100 / SSR 500）。

### 5.4 実績バッジ

| 系統 | 条件 |
|---|---|
| 累計時間 | 1 時間 / 10 時間 / 50 時間 / 100 時間 / 500 時間 / 1000 時間 |
| 連続日数（最長） | 3 日 / 7 日 / 30 日 / 100 日 / 365 日 |
| 記録回数 | 1 回 / 10 回 / 100 回 / 1000 回 |
| タグ数（記録に使ったタグの種類） | 3 種 / 10 種 |
| 1 日の勉強時間 | 3 時間 / 6 時間 |
| レベル | Lv5 / Lv10 / Lv25 / Lv50 |

バッジは記録から都度判定する。記録を削除して条件を下回った場合、そのバッジは未解除に戻る。

## 6. データモデル (SwiftData)

| モデル | 項目 |
|---|---|
| `StudySession` | `id`、`startedAt`（開始日時）、`minutes`、`tag`（任意、`Tag` への参照）、`memo`、`source`（計測 / 手入力） |
| `Tag` | `id`、`name`、`colorHex`、`createdAt` |
| `OwnedReward` | `rewardID`（景品カタログの ID）、`obtainedAt` |
| `PlayerState`（1 件のみ） | `gachaTickets`（券残数）、`bonusXP`（ダブり変換の累計）、`equippedTitleID`、`equippedThemeID` |

- 計測中タイマーの開始日時は `UserDefaults` に保存する。
- 景品カタログとバッジ定義はコード内の静的データとする。
- XP・レベル・連続日数・バッジ解除状況は保存せず、記録から都度計算する。記録を編集・削除しても矛盾が生じない。
- 1 日あたりの券付与数は、その日付の 15 分以上の記録件数から算出する（新規保存前の件数が 3 未満なら付与）。

## 7. アーキテクチャ

```
Packages/StudyCore/   UI にも SwiftData にも依存しない純粋な Swift パッケージ
  Sources/StudyCore/
    Leveling        XP → レベル、次レベルまでの進捗
    Streak          勉強した日 → 現在 / 最長の連続日数
    Stats           記録一覧 → 日別合計、タグ別合計、累計
    Heatmap         草カレンダーの格子と濃淡
    TimerMath       経過秒 → 分
    Rewards         景品カタログ
    Gacha           抽選（乱数生成器を注入）、券付与判定
    Badges          統計値 → 解除済みバッジ
    Progress        進捗スナップショット、保存結果の評価
  Tests/StudyCoreTests/
EndlessStudy/
  App/            アプリのエントリポイント、タブ構成、ModelContainer 設定
  Models/         SwiftData モデル
  Services/       RecordService（保存・券付与・ガチャ）、TimerStore
  Features/
    Home/         ホーム、タイマー
    Record/       保存シート、手入力、結果画面
    History/      草カレンダー、タグ別累計、履歴、編集
    Collection/   ガチャ、景品一覧、バッジ一覧
  Support/        テーマ色、表示用フォーマッタ
project.yml         XcodeGen 定義
```

- `StudyCore` は `Foundation` のみに依存する。値型の入力（分数・日付の配列など）を受け取り、値を返す関数群とする。カレンダーと現在日時、乱数生成器は引数で注入する。Xcode がなくても `swift test` でテストできる（Linux では Docker の `swift` イメージを使う）。
- View は `@Query` で記録を取得し、`StudyCore` に渡して表示用の値を得る。
- 保存処理（記録の追加、券付与、結果の組み立て）は 1 か所（`RecordService`）にまとめ、タイマーと手入力の両方から使う。

## 8. エラー処理・境界条件

- SwiftData の保存に失敗した場合はアラートを表示し、入力内容は保持する。
- タイマー計測中にアプリが終了しても、次回起動時に計測中の状態を復元する。
- 端末の時計が変更されて開始日時が未来になった場合、経過時間は 0 として扱う。
- 日付をまたぐ記録は開始日時の日付に全量を計上する（分割しない）。
- 券が 0 枚のときはガチャのボタンを無効にする。

## 9. テスト

`StudyCore` をユニットテストで検証する。

- Leveling: 境界値（99 XP → Lv1、100 XP → Lv2 など）
- Streak: 今日記録あり / 昨日まで / 途切れ / 記録なし / 最長の算出
- Badges: 各系統の境界値
- Gacha: 固定シードの乱数でレアリティ分布と景品選択、ダブり時の XP 変換、券付与（15 分未満、1 日 3 枚上限）
- Stats: 日別・タグ別の集計、日付またぎ

UI は Xcode プレビューと実機で手動確認する。

## 10. 初版に入れないもの

- 通知リマインダー
- ウィジェット、Live Activity
- iCloud 同期、データのエクスポート
- 目標（資格・言語）との紐付け、目標時間の設定
- 連続日数の救済アイテム
- 日付区切り時刻の変更

## 11. 開発上の制約

開発環境が Linux のため、Xcode でのビルドとシミュレータ確認はこの環境では行えない。`StudyCore` は Docker 上の Swift でテストし、アプリ本体は構文チェックまでとする。アプリの初回ビルドは Mac 上で `xcodegen generate` を実行して Xcode で開き、コンパイルエラーが出た場合はその内容をもとに修正する。
